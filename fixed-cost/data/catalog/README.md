# B1 카탈로그

`npm run validate` 또는 `npm run validate:catalog`로 실제 카탈로그 3개를 검사해요. 실패하면 종료 코드 1과 파일·배열 위치·필드가 나오고, 다른 서비스 사이의 별칭 중복은 경고만 출력해요. JSON 형식과 필수 값, 날짜, 정수 가격, id 중복, 서비스·요금제·멤버십 참조를 검사해요.

`lib/catalog.ts`는 실제 JSON 3개만 정적 import하므로 브라우저에서도 사용할 수 있어요. `loadCatalog()`는 검증된 `Catalog`를 반환해요. `validateCatalog(input)`은 테스트·검증 도구에서도 사용할 수 있는 순수 함수이고, 경고를 함께 반환해요. mock 파일은 실제 로더에서 읽지 않아요.

## 초기 서비스 값의 근거

BACKEND.md 4부 1절에서 초기 입력을 허용한 7개 서비스만 넣었어요. 아래 금액은 가이드의 초기 자료이며, 새로 공식 가격을 확인했다는 뜻은 아니에요. 모든 서비스의 `checked_at`·`cancel_url`은 `null`, `email_domains`는 `[]`예요. 요금제 이름이 자료에 없으면 `요금제 이름 확인 필요`라고 표시했어요. 요금제 id와 서비스 분류는 앱 내부 식별·분류용이에요.

| 서비스 | 초기 가격 | 근거·보류 이유 |
| --- | --- | --- |
| 넷플릭스 스탠다드 | 월 13,500원 | 가이드 허용 초기값 |
| 티빙 베이직 | `null` | 가이드의 9,500원은 합계에서 역산한 값으로 공식 재확인 필요 |
| 아이클라우드 | 월 1,100원 | 가이드 허용 초기값, 요금제 이름 확인 필요 |
| 다글로 | 월 14,900원 | 가이드 허용 초기값 |
| 카카오톡 이모티콘 플러스 | 월 6,900원 | 가이드 허용 초기값 |
| 굿노트 연간 | 연 50,500원 | 가이드 허용 초기값 |
| 네이버플러스 멤버십 | 월 4,900원 | 가이드 허용 초기값 |

`benefits.json`·`bundles.json`은 빈 배열이에요. 공식 조건 원문·출처 URL·확인일이 없거나 비어 있는 실제 혜택·묶음 항목은 검증에 실패해요. 조건 원문은 공백·줄바꿈을 변경하지 않아요.

`benefits.mock.json`의 `_mock: true`와 혜택 3개는 개발·테스트 전용이에요. 금액·학교·조건·2000-01-01 확인일은 전부 가짜이며 `example.invalid` 링크는 공식 출처가 아니에요. 실제 제공 혜택이나 보고서 근거로 사용하면 안 돼요.
